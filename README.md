# 세계 외국어 시험 총정리 · World Language Exams

전 세계 외국어 능력시험 64종(29개 언어)의 **레벨·응시료·국가별 응시장소/접수 사이트·공식 모의고사·대표 준비서적** 링크를 한곳에 모은 사이트입니다.

- 사이트: https://yalli2.github.io/worldlanguage/
- 메뉴: 홈 · 시험 찾기(필터) · 국가별 응시처 · 한눈에 비교 · CEFR 대조 · 준비서적
- 시험마다 공식 교재·국내 베스트셀러·해외 대표 준비서적 소개 (138권)
- 화면 언어: 한국어 / English / Español / 日本語 / 中文 / Français
- 디자인: event4students 사이트와 같은 형식

## 데이터
- `data/*.json` — 언어권별 원본 조사 자료, `data/books_*.json` — 준비서적 (2026년 11월 조사)
- `tools/build.py` — 원본을 합쳐 `data.js` 생성: `python3 tools/build.py data.js` 

응시료·일정은 수시로 바뀝니다. 접수 전 반드시 각 공식 사이트에서 확인하세요.
